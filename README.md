# 한국 주식 자동매매 — 키움 시세 + 로컬 모의매매

가상 자금으로 이동평균 교차 전략을 실행하는 Node.js 프로그램입니다. 별도 npm 패키지가 필요 없습니다.

**웹 배포:** [Render 배포 및 로그인 안내](DEPLOY.md) · [Render에 배포하기](https://render.com/deploy?repo=https://github.com/stun1012/kiwoom-autotrader)

**현재 구현 범위: 데모 자동매매, 키움 REST API 시세 조회를 이용한 로컬 모의매매, CSV 백테스트. 키움 모의투자 계좌 주문과 실계좌 주문은 구현하지 않았습니다.**

## 실행

Node.js 24 이상이 필요합니다. Windows에서 `start.cmd`를 더블클릭한 뒤 브라우저에서 <http://127.0.0.1:8765>를 엽니다. 또는 프로젝트 폴더에서:

```powershell
node server.mjs
```

1. 기본 설정으로 **자동매매 시작**을 누르면 가상 시세가 1초마다 생성됩니다.
2. 단기/장기 평균의 상향 교차에서 매수하고, 하향 교차 또는 손절/익절 신호에서 매도합니다. 처음 장기 표본 수만큼은 준비 구간입니다.
3. 설정을 변경하려면 정지한 뒤 **설정 적용 / 세션 초기화**를 누릅니다. 입력만 바꿔서는 실행 중인 전략에 적용되지 않습니다.
4. **정지**는 추가 처리를 멈추며, 보유분을 청산하지 않습니다. 시작하면 이어서 실행합니다.
5. 서버는 터미널에서 Ctrl+C로 종료합니다.

## 키움 시세 연결

1. [키움 REST API 포털](https://openapi.kiwoom.com/main/home)에서 서비스 신청 및 사용할 환경의 앱키/시크릿키를 준비합니다.
2. `.env.example`을 `.env`로 복사하고 자신의 키를 **로컬 파일에만** 입력합니다.
3. `KIWOOM_ENV=mock`은 키움 모의 서버, `production`은 운영 서버 시세를 조회합니다. 이 설정은 주문을 활성화하지 않습니다.
4. 서버를 재시작합니다. 대시보드에서 **키움 시세**를 선택하고 6자리 종목코드를 입력한 뒤 설정 적용 → 시작을 누릅니다.

키움 시세는 60초 간격으로 조회합니다. 누적 거래량이 직전 응답과 같으면 새 표본을 만들지 않습니다. 표본은 완성된 1분봉이 아닌 조회 시점의 현재가입니다. 장 마감·휴일에는 새 거래량이 없어 대기할 수 있습니다. 데이터 시각은 서버 수신 시각이며 거래소 체결 시각이 아닙니다. 서버 연결/인증/기록 저장 오류가 발생하면 자동 정지하고 오류를 표시합니다.

API 키는 브라우저로 전달하지 않습니다. `.env`와 `data/`는 Git에서 제외됩니다. 키움에 대한 실제 인증과 시세 조회는 키 입력 후 확인해야 합니다. 자동 테스트는 모의 HTTP 응답을 사용합니다.

## 거래량 상위 종목 매수 조건

키움 시세 모드에서는 **당일 거래된 주식 수 상위 20종목**에 포함된 경우에만 신규 매수합니다. 상위 범위는 화면에서 1~50종목으로 변경할 수 있습니다. KRX 전체 시장, 장중 거래량, 관리종목 제외 조건으로 키움 `ka10030`을 조회합니다. 거래대금 또는 평소 대비 증가율 기준이 아닙니다. 키움 서버가 반환한 순서의 첫 N개를 사용하며 첫 페이지가 N개보다 적으면 반환된 종목만 대상으로 삼습니다.

목록에서 거래할 종목을 선택하고 설정을 적용하세요. 현재 버전은 선택한 **한 종목**을 거래하며 상위 종목 전체를 자동 순환 매매하지 않습니다. 매수에는 순위 조건과 이동평균 상향 교차가 모두 필요하고, 체결 직전에도 순위를 재확인합니다. 순위 밖이면 대기 중인 매수를 취소합니다. 보유분의 기존 매도 조건은 순위와 관계없이 유지합니다.

순위는 시세 조회 주기마다 갱신합니다. 순위 조회 실패 시 신규 매수를 차단하고 시세 조회가 가능하면 보유분 매도 처리를 이어갑니다. 키움 키와 순위 API의 실제 연결은 별도 확인이 필요합니다. 가상 시세와 단일 종가 CSV 백테스트에는 전체시장 순위 데이터가 없어 이 필터를 적용하지 않습니다.

참고: [키움 공식 당일거래량상위 API 예제](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/examples/%EA%B5%AD%EB%82%B4%EC%A3%BC%EC%8B%9D/%EC%88%9C%EC%9C%84%EC%A0%95%EB%B3%B4/get_domestic_today_volume_top.py).

## CSV 사용 방법

`sample.csv`는 합성 데이터이며 실제 종목 가격이 아닙니다. 백테스트 패널에서 선택해 실행할 수 있습니다. 자신의 CSV는 날짜 오름차순, 날짜 중복 없음, 양수 가격을 사용합니다.

```csv
date,close
2026-01-01,70000
2026-01-02,70500
```

날짜는 `YYYY-MM-DD` 또는 시간대가 포함된 ISO 8601 형식을 권장합니다. CSV는 쉼표 구분 숫자 가격을 지원하며 따옴표로 감싼 필드나 천 단위 쉼표는 지원하지 않습니다. 업로드는 최대 4.5MB, 100000개 가격 행입니다. 백테스트는 현재 입력한 전략을 사용하며 실행 중인 모의 계좌와 독립입니다.

## 체결 및 위험 한도의 의미

- 매수/매도 신호는 다음 표본 가격에 슬리피지를 반영해 체결합니다. 신호가 생성된 가격으로 소급 체결하지 않습니다.
- 한 종목, 현금 매수, 정수 수량입니다. 투자 비중은 매수 시 평가자산 대비 한도이며 보유 중 비중을 재조정하지 않습니다.
- 손절/익절은 매입 수수료 포함 원가 대비 가격 변화를 기준으로 합니다. 다음 표본에서 체결하므로 지정 손절률보다 손실이 커질 수 있습니다.
- 누적 손실 한도는 초기 자금 대비 평가손실입니다. 일별 한도가 아닙니다. 도달 시 현재 표본에서 모의 청산하고 재진입을 차단합니다. 가격 급변과 비용으로 한도를 초과할 수 있습니다.
- 수수료·세금·슬리피지 값은 예시입니다. 매도 세금 기본값은 0이며 사용자가 상품과 적용 시점에 맞게 입력해야 합니다. 거래소 호가 단위, 주문 대기, 부분 체결, 거래정지, 배당, 주식분할, 수정주가는 모델링하지 않습니다.
- 마지막 보유분은 마지막 가격으로 평가하며, 백테스트 종료 시 강제 청산하지 않습니다. 최종 평가자산에는 미매도 물량의 미래 매도 비용이 포함되지 않습니다.
- 계좌 상태는 메모리에서만 유지합니다. 서버 재시작 시 새 가상 계좌로 시작합니다. `data/trades.jsonl`에는 모든 세션 체결을 추가 저장하며 자동 복구에는 사용하지 않습니다. 화면은 최근 200건, CSV 다운로드는 현재 세션 전체 체결입니다.

실계좌 자동주문까지 확장하려면 주문 접수/미체결/부분 체결/잔고 대조, 재시작 복구, 거래시간과 휴장일 처리를 별도로 구현하고 검증해야 합니다.
